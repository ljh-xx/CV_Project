# Few-shot Image Recognition Submission

## 1. Environment

Use Python 3 with PyTorch. A tested dependency snapshot is in
`requirements.txt`.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

GPU is recommended. CPU inference also works, but is slower.

## 2. Dataset Path

The package does not include the dataset. Put or pass the official data root:

```text
DLUT_VLG_2026_本科生/data
```

The data root must contain:

```text
pretrain/
Task1/
Task2/
Task3/
Task4/
```

## 3. Final Model

The final model file is:

```text
../模型文件/best_model.pth
```

It is a bundle with four task-specific `se_resnet18` student classifiers:

```text
Task1, Task2, Task3, Task4
```

Each student uses the same ResNet-based architecture and a task-specific final
classification head. Public DINOv2 models were used only as distillation
teachers. The submitted score files are generated by the student models.

## 4. Inference

Generate one task:

```bash
python infer.py \
  --task Task1 \
  --data-root /path/to/DLUT_VLG_2026_本科生/data \
  --model-file ../模型文件/best_model.pth \
  --result ../Score \
  --cuda
```

Generate all four score files:

```bash
python generate_score.py \
  --data-root /path/to/DLUT_VLG_2026_本科生/data \
  --model-file ../模型文件/best_model.pth \
  --result ../Score \
  --cuda
```

Or use the wrapper:

```bash
bash run_reproduce.sh /path/to/DLUT_VLG_2026_本科生/data --cuda
```

Remove `--cuda` if no GPU is available.

## 5. Final Score Files

The final submitted files are:

```text
../Score/Task1_score.csv
../Score/Task2_score.csv
../Score/Task3_score.csv
../Score/Task4_score.csv
```

Important: the final submission is `Score/Taskx_score.csv`, not
`test_predictions.csv`.

## 6. Params and FLOPs

The final student architecture is `se_resnet18`.

```text
Params: 11.311M
FLOPs : 0.289 GFLOPs
```

Both are below the required limits of 15M parameters and 2G FLOPs.

## 7. Best Result

Local validation average accuracy:

```text
93.21%
```

The hidden test labels are not included locally, so hidden test accuracy cannot
be directly measured in this package.

## 8. Random Seed

Main distillation seed:

```text
2026
```

## 9. Reproduction Notes

The final `Score/` files in this package were generated from the student
bundle in `模型文件/best_model.pth`. The teacher score files used during
distillation are not required for inference.
